# Frontend (Next.js 16, App Router, TypeScript): the HomeLens AI website and live demo, in the Daylight style

One self-contained app: a product website plus the working demo. It imports Rithik's anonymized data as JSON (`data/`) and analyses pasted reviews in its own route handler (`app/api/analyze/route.ts`). No backend, no required environment variables.

```bash
npm install
npm run dev            # http://localhost:3000
npm test               # parity tests: the TypeScript engine vs Rithik's Python model (data/golden.json)
npm run typecheck && npm run build
```

## Routes
| Route | Page |
|---|---|
| `/` | home: hero, live analyzer, features, screenshots, aspects, Responsible AI |
| `/product`, `/how-it-works`, `/pricing`, `/security`, `/docs` | product, methodology (real model metrics), plans (no invented prices), Responsible AI and privacy, API docs |
| `/about`, `/faq`, `/contact`, `/changelog`, `/privacy`, `/terms` | company and legal pages |
| `/demo` | the command center: KPI cards, provider leaderboard, aspect radar, evidence feed, triage dock |
| `/api/analyze` | POST `{ text }` → review analysis |
| `/sitemap.xml`, `/robots.txt`, `/opengraph-image` | SEO |

## Code map
* `app/base.css` design system (tokens, liquid-glass surfaces, buttons); `app/site.css` marketing pages; `app/demo/demo.css` demo. Route group `app/(site)/` shares the header and footer; `app/demo/` has its own layout.
* `components/site/` website pieces (`SiteHeader`, `SiteFooter`, `ui`, `LiveAnalyzer`, `HeroPreview`). `components/` also holds the demo (`KpiPods`, `Leaderboard`, `AspectBlob`, `EvidenceFeed`, `TriageDock`).
* `lib/engine/` TypeScript port of Rithik's masking, phrase dictionary and TF-IDF model. `data/` is generated by `../scripts/export_frontend_data.py`: never edit by hand.

## Look and performance rules
* Liquid glass is static CSS (frosted gradient, bright rim, inner highlight). Real `backdrop-filter` is used only for the header, the demo bar, the mobile menu and the dock, because they overlap scrolling content; all other panes sit on the static backdrop.
* No canvas, no infinite decorative animation, nothing animates layout on hover. The aspect radar pauses off-screen and idles at ~20 fps. Leaderboard detail panels mount on first open.
* Style: warm cream paper, Instrument Serif headlines (italic for emphasis), JetBrains Mono numbered labels, Inter body, sun-orange accent, yellow step cards, a periwinkle/navy band and dark dusk photo bands. Tier colours (Stable, Watch, Elevated, High concern) are reserved for risk and always have a text label; Elevated is a deep rust so it never reads as the orange accent. Motion respects `prefers-reduced-motion`.
* Imagery: `public/img/dusk.webp` and `sunset.webp` are original procedural scenes made by `../scripts/make_site_images.py` (no third-party photos); `leaderboard/evidence/overview/aspects/triage.webp` are screenshots of `/demo`.
* Optional env vars (see `.env.example`): `NEXT_PUBLIC_CONTACT_EMAIL`, `NEXT_PUBLIC_REPO_URL`, `NEXT_PUBLIC_SITE_URL`. Without them the site shows no contact address or repo link rather than a dead one.
