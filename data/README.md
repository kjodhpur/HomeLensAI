# Data

**Nothing in `raw/`, `processed/`, `cache/` or `annotation/` is committed** (see `.gitignore`): the Yelp Open Dataset licence does not allow redistributing the data.
Each teammate downloads it once.

## Option A — the Milestone 1 extract (recommended)
Put the file the team already built here:

```
data/raw/HomeLens_Yelp_HomeServices.csv      # 23,685 reviews · 1,403 Tucson, AZ home-service businesses · 2006–2022
```

The notebook accepts any of these column spellings (see `COLUMN_ALIASES` in Section 3): `review_id, business_id, text, date, categories`, the review-level star
column (`review_stars`, `stars`, or `stars_x`/`stars_y` after a merge), and optionally `name`/`business_name`, `city`, `state`, `business_stars`, `review_count`.

## Option B — rebuild the extract from the raw Yelp files
1. Download the **Yelp Open Dataset** (JSON) from <https://business.yelp.com/data/resources/open-dataset/> or the Kaggle mirror <https://www.kaggle.com/datasets/yelp-dataset/yelp-dataset>
   (`kaggle datasets download -d yelp-dataset/yelp-dataset` with your Kaggle API token).
2. Unzip these two files into `data/raw/`:
   ```
   data/raw/yelp_academic_dataset_business.json
   data/raw/yelp_academic_dataset_review.json      # ~5 GB — streamed in chunks, never loaded whole
   ```
3. Run the notebook. Section 3 streams the review file once, keeps Tucson, AZ home-service businesses, and writes `data/raw/HomeLens_Yelp_HomeServices.csv` for next time.

## No data at all?
`data/sample/sample_reviews.csv` is a **synthetic** dataset (40 fake providers, ~1,170 reviews) generated by `scripts/make_sample_data.py`. The notebook falls back to it automatically and prints a
**DEMO MODE** banner. It exists so the pipeline, the API and the web app can be built and tested without the real data. Its numbers are *not* results.

## Folders
| Path | Content | In git? |
|---|---|---|
| `data/raw/` | Yelp extract / raw JSON | no |
| `data/sample/` | synthetic reviews + `outputs/` (JSON the pipeline produced from them) | **yes** |
| `data/processed/` | JSON artifacts from the **real** run (`provider_risk.json`, `summary.json`, `aspect_lexicon.json`) | no |
| `data/cache/` | cached DistilBERT predictions + aspect extraction | no |
| `data/annotation/` | the aspect-precision audit CSV the team labels | no |
